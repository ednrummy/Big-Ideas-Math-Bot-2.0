# Big-Ideas-Math-Bot-2.0
This is a reworked version of BIM Bot, a cheat that gives you the answers to Big Ideas Math problems. This version erases the inconvenience of creating an entire extremely suspicious window and opening the console to get the answers.

# What we did:
First, we decoded and reverse engineered the original BIM BOT program.
Then, we cleaned it up by:
1. Completely removing the need for an entire window with a button to log the answers in the console
2. Displaying the answers in a dissmisble normal looking alert window. (If it is a graphing question, it creates a very minimilastic draggable window with a transparent background and small but visible black text displaying the points to plot on the graph.

# HOW TO USE

When dealing with a normal question (A/B/C/D , Number answers, etc) it simply creates a dissmisable alert window displaying the answers
When dealing with a graphinh question, it creates a very minimilastic draggable window with a transparent background and small but visible black text displaying the points to plot on the graph. (USE THE , KEY TO SHOW/HIDE IT and USE THE . KEY TO DELETE IT COMPLETELY)
